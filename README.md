# Excel Regression Analysis & Bike Sales Dashboard

Project Overview:
This project demonstrates two key components using Excel:

## End-to-End Regression Analysis in Excel

* Performed a complete regression analysis using Excel's built-in tools, from data cleaning and preparation to executing and interpreting the regression model.
* The dataset was pre-processed and analyzed to understand relationships between independent variables and the target variable.
Excel features such as Data Analysis Toolpak, Pivot Tables, and Charts were utilized to build a comprehensive model and evaluate performance.


## Bike Sales Dashboard

* Created an interactive Excel dashboard to visualize bike sales data.
Used Excel's features like Slicers, Pivot Charts, and Conditional Formatting to create insights into key sales trends, customer demographics, and performance metrics.
* The dashboard is designed for ease of use and provides high-level overviews, as well as drill-down capabilities for more detailed insights.


## Key Features
### End-to-End Regression in Excel
* Data Cleaning and Preparation
* Regression Model Creation
* Model Evaluation (R-squared, p-values, etc.)
* Residuals Analysis

### Bike Sales Dashboard
* Sales Trends Visualization
* Customer Demographic Insights
* Monthly and Yearly Sales Comparisons
* Interactive Filtering via Slicers
